# 2027 채용연계형 인턴십 포트폴리오 인터뷰

사용자가 직접 확인한 사실만 기록한다. 웹 문구의 근거이며, 정량 성과나 코드 작성 지분은 별도 확인 없이 추가하지 않는다.

## Visual Shooting Code / GameProject1

- 제작 기간: 5일 이내. 팀 규모: 4인.
- PUBG BLINDSPOT에서 영감을 받아 시작했다. 초기에는 섬광탄을 사용하는 Rainbow Six 스타일의 전술을 기획했고, 이후 Overwatch처럼 클래스를 다양화하면서 아군·상대 조합 균형에 초점을 맞췄다.
- 클래스 다양화를 제외한 기획 대부분을 담당했다. 대표 개인 기여는 시야 처리와 연막 안팎의 시야 규칙이다.
- Counter-Strike·VALORANT를 참고해 원거리 캐릭터에게 유리한 시야를 차단하려고 연막을 설계했다.
- 테스트 전후 성과 수치는 제공되지 않았다. 병과 다양화 아이디어나 전체 코드 구현을 개인 단독 성과로 표기하지 않는다.

## 5일 뒤 마왕 / GameProject2

- 제작 기간: 5일 이내. 팀 규모: 3인.
- Vampire Survivors와 리그 오브 레전드 집중포화에서 영감을 받았다. 반복 생존보다 성장하며 단계를 넘어 최종 목표에 도달하는 경험을 의도했다.
- 기획의 대부분을 담당했다. 레벨 디자인, 낮에는 성장·밤에는 웨이브 방어를 하는 규칙과 플레이어 전략에 집중했다.
- 특히 싱글플레이의 수비·추종 AI 동료 역할 분담에 신경 썼다.
- 협동에서는 시간제한과 야간 방어 제약으로 역할 분담을 유도했다. 웨이브 몬스터의 경험치 보상을 낮춰 방어만으로 성장하는 수단을 제한하고, 밤에도 일부 인원이 탐험을 이어가도록 했다.
- 실제 플레이테스트에서는 낮의 성장 정도에 따라 후반에도 1인 완막이 가능했다.
- 증강 효과를 하향하고 클로즈드 루프의 레벨업 경험치를 조정했다. 후반 방어에 2명이 필요하도록 맞추는 것이 조정 목표였다.
- 정확한 변경 전후 값, 테스트 표본 수, 승률 등은 제공되지 않았다.

- 개인 담당: AI 처리 흐름의 설계와 구축. YOLO로 영역을 추출한 뒤 MediaPipe로 관절을 추출한다.
- 동작 판정식, 논문 집필 전체, 실험 정확도를 개인 담당·성과로 추정하지 않는다.
